   → Check Console for any errors
   → Restart Unity if needed

❌ NavMesh won't bake?
   → Ensure walls have "NavigationStatic" tag
   → Check NavMesh layer settings
   → Try: Window > AI > Navigation > Clear All > Bake

❌ Furniture overlapping?
   → This is expected - they are placeholder cubes
